# صيّاد اللؤلؤ 🦪

لعبة تعليمية للقسمة لطلاب الصف الخامس الابتدائي بأجواء الغوص على اللؤلؤ.

**من عمل: صفاء السيد مصطفى**

## المستويات (الهيرات)
1. الهير القريب: حقائق القسمة
2. هير الشط: قسمة عدد من ٣ أرقام على رقم واحد
3. هير المحار: القسمة مع الباقي
4. الهير العميق: القسمة على عدد من رقمين
5. هير الدانة: مسائل كلامية من رحلة الغوص

زر «حبل السيب» يعرض خطوات القسمة الطويلة خطوة بخطوة.
